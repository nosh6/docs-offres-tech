# docs-offres-tech

Documentation publique d'[offres.tech](https://offres.tech), rendue par [Mintlify](https://mintlify.com).

- `docs.json` : configuration du site (thème, couleurs, onglets, pages).
- `*.mdx` : les pages, une par entrée de navigation.
- `logo/`, `favicon.svg` : l'identité du site principal, reprise telle quelle.

Aperçu local : `npx mint dev`. Les règles d'écriture sont dans `CLAUDE.md`.
